# UniMusic: вся музыка в одном приложении (Mac + iPhone)

## Что умеет
- **Единый поиск** сразу в Apple Music, Spotify и YouTube. Одинаковые треки склеиваются в одну строку с бейджами сервисов, где они есть.
- **Умное воспроизведение по приоритету.** В Настройках задаётся порядок сервисов (по умолчанию Apple Music → Spotify → YouTube Music → YouTube → SoundCloud → Яндекс → VK). Трек включается в первом сервисе, где он есть.
- **Синхронизация через song.link.** Если трека нет в нужном сервисе, приложение само ищет его во всех остальных, включая SoundCloud и Яндекс Музыку.
- **Вкладка «По ссылке».** Вставьте ссылку из любого сервиса (например, Spotify от друга) и сразу увидите, где ещё есть этот трек.
- **Смешанные плейлисты и Избранное.** В одном плейлисте могут быть треки из разных сервисов. На YouTube и в Apple Music (на iPhone) следующий трек включается сам.

## Как воспроизводится каждый сервис
| Сервис | iPhone | Mac |
|---|---|---|
| Apple Music | прямо в приложении, через системный плеер (нужна подписка) | открывается в приложении «Музыка» |
| YouTube | встроенный плеер в приложении | встроенный плеер в приложении |
| Spotify | открывается в приложении Spotify | открывается в Spotify |
| YouTube Music, SoundCloud, Яндекс | открывается в их приложении или на сайте | то же самое |
| VK Музыка | только поиск в VK (открытого API нет) | то же самое |

> Внутри одного приложения нельзя проигрывать Spotify, SoundCloud и VK: их правила это запрещают. Поэтому UniMusic находит трек и сразу открывает его в нужном приложении.

## Как запустить (Терминал не нужен)
1. Установите **Xcode** из App Store (бесплатно, ~10 ГБ) и один раз откройте его, чтобы он доустановил компоненты.
2. Распакуйте архив и дважды кликните **UniMusic.xcodeproj**.
3. Xcode → Settings → Accounts → «+» → войдите своим Apple ID (обычным, бесплатным).
4. Слева нажмите на синюю иконку **UniMusic** → таргет **UniMusic-macOS** → вкладка **Signing & Capabilities** → в поле **Team** выберите себя. То же для таргета **UniMusic-iOS**.
5. **Запуск на Mac:** вверху окна выберите схему **UniMusic-macOS** → «My Mac» → нажмите ▶︎ (или ⌘R).
6. **Запуск на iPhone:**
   - подключите iPhone кабелем, на телефоне нажмите «Доверять этому компьютеру»;
   - вверху выберите схему **UniMusic-iOS** и свой iPhone → ▶︎;
   - если iPhone просит **Режим разработчика**: Настройки → Конфиденциальность и безопасность → Режим разработчика → вкл, перезагрузка;
   - при первом запуске: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».

> С бесплатным Apple ID приложение на iPhone работает **7 дней**, потом просто снова нажмите ▶︎ в Xcode (данные сохранятся).
> Если Xcode пишет, что Bundle Identifier занят, поменяйте его на вкладке Signing на любой свой, например `com.ivan.unimusic`.

## Импорт плейлистов
Медиатека → «Импорт из Spotify и Apple Music».
- **Apple Music:** нажмите «Показать плейлисты медиатеки» и разрешите доступ. На iPhone берётся медиатека «Музыки» на телефоне, на Mac — медиатека приложения «Музыка».
- **Spotify:** в developer.spotify.com → ваше приложение → Settings → **Redirect URIs** добавьте `unimusic://spotify-callback`, вставьте Client ID в Настройки UniMusic и нажмите «Войти в Spotify». Доступны все ваши плейлисты и «Любимые треки».
- Повторный импорт того же плейлиста **обновляет** его — так плейлисты синхронизируются.
- После импорта треки сами находятся в остальных сервисах при воспроизведении (или через меню трека → «Найти во всех сервисах»).

## Ключи (необязательно, но нужны для поиска по Spotify и YouTube)
Для поиска нужны Client ID + Secret, для импорта — только Client ID. Без ключей поиск идёт по Apple Music, а остальные сервисы находятся через song.link.
- **Spotify:** https://developer.spotify.com/dashboard → Create app → Redirect URI `unimusic://spotify-callback` → отметьте Web API → скопируйте Client ID и Client Secret в Настройки приложения.
- **YouTube:** https://console.cloud.google.com → создайте проект → включите *YouTube Data API v3* → Credentials → Create API key → вставьте в Настройки.

Ключи хранятся в Связке ключей.

## Структура
```
Sources/
  App/UniMusicApp.swift          точка входа
  Models/                        трек, сервисы, настройки, медиатека (JSON)
  Services/                      поиск Apple (iTunes API), Spotify, YouTube, song.link
  Playback/PlayerController.swift выбор сервиса по приоритету, очередь
  Playback/YouTubePlayerView.swift встроенный YouTube
  Views/                         интерфейс SwiftUI
```

## Раздать приложение другим
В папке `.github/workflows` лежит автосборка. Загрузите проект на GitHub (публичный репозиторий бесплатный). GitHub сам соберёт:
- **UniMusic.dmg** для Mac;
- **UniMusic.ipa** для iPhone (ставится через Sideloadly).

Чтобы опубликовать версию, создайте на GitHub Release с тегом `v1.0`, и файлы прикрепятся к нему автоматически. Ссылку на страницу Releases можно отправлять друзьям вместе с файлом `УСТАНОВКА.md`.
