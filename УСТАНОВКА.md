# Как установить UniMusic (для друзей)

Размер: около 3–6 МБ.

## Mac
1. Скачайте **UniMusic.dmg**, откройте его и перетащите UniMusic в папку «Программы».
2. При первом запуске macOS скажет, что не может проверить разработчика. Это нормально: приложение не прошло платную проверку Apple.
   - Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **«Всё равно открыть»**.
   - На старых macOS: правый клик по UniMusic → «Открыть» → «Открыть».
3. Больше это окно не появится.

## iPhone (бесплатный способ)
Apple не даёт ставить приложения не из App Store по ссылке. Поэтому нужна программа **Sideloadly** на компьютере (Mac или Windows):
1. Скачайте Sideloadly с sideloadly.io и установите.
2. Подключите iPhone кабелем.
3. Перетащите **UniMusic.ipa** в Sideloadly, введите свой Apple ID и нажмите **Start**.
4. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → **Доверять**.
5. Если iPhone просит **Режим разработчика**: Настройки → Конфиденциальность и безопасность → Режим разработчика → вкл.

Через 7 дней приложение перестанет открываться. Чтобы продлить, снова нажмите Start в Sideloadly (данные сохранятся). Так работают все бесплатные Apple ID.

## После установки
- Поиск по Apple Music и «По ссылке» работают сразу, без настройки.
- Поиск по Spotify и YouTube и импорт из Spotify требуют своих бесплатных ключей. Как их получить, написано в Настройках приложения.
